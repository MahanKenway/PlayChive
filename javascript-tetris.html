JavaScript Tetris: frequently asked questions

Is JavaScript Tetris free to play on PLAYCHIVE?

Yes. JavaScript Tetris runs free in your browser. PLAYCHIVE bundles the engine and the game content it needs, distributed under their own open or freeware terms (MIT · source and notices retained). There is no sign-up and no file upload step.

Do I need to install anything to play JavaScript Tetris?

No. JavaScript Tetris runs directly in a modern desktop or mobile browser such as Chrome, Edge, Firefox or Safari, using WebAssembly or HTML5. No account is required.

Can I play JavaScript Tetris on a phone or with a controller?

PLAYCHIVE supports keyboard, on-screen touch controls, gamepad and fullscreen mode. Where the runtime allows it, phones get PSP-style on-screen controls, and desktop browsers accept keyboard, mouse and a connected gamepad.

Who makes JavaScript Tetris and what is its license?

JavaScript Tetris is developed by Jake Gordon & Richard Birkby. License and attribution: MIT · source and notices retained. PLAYCHIVE is a non-commercial hub and keeps upstream notices with each runtime.
