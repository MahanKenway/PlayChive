# Privacy Policy

**Last updated: 29 September 2026.** PLAYCHIVE is a static browser game hub maintained by Mahan Tavakoli. This policy explains what the public site can access and how long information remains available.

## Information PLAYCHIVE handles

PLAYCHIVE does not require an account, collect a name or email address, or operate a first-party advertising profile. Game preferences, theme, audio settings, library pins, and local save data are stored in your browser using local storage. They remain on your device until you clear them or the browser removes them.

The site may request public game assets, open-source runtime files, fonts, and official project links from GitHub Pages, Google Fonts, or upstream hosts. Those hosts may receive ordinary technical request data such as an IP address, user agent, and timestamp under their own policies. PLAYCHIVE does not combine those requests into a personal profile.

## Uploaded files

Optional WAD imports are read locally by the browser to start a game. PLAYCHIVE does not upload those files to its own server. Do not select files containing personal or confidential information.

## Retention and choices

PLAYCHIVE has no first-party server database for player data. Browser preferences and saves persist locally until you delete them; public static assets remain published while their upstream project or deployment remains available. You can clear site data in browser settings, use private browsing, or disable audio and local storage through browser controls.

## External projects

Catalog entries can link to third-party project pages and downloads. Their privacy, licensing, logging, and retention practices are controlled by those providers. Review the applicable upstream policy before following an external link.

For a privacy question about this site, contact the project owner through [GitHub / MahanKenway](https://github.com/MahanKenway).
