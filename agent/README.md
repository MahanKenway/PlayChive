# PLAYCHIVE Agent Discovery

This directory is a static, no-login, no-cookie discovery surface for browser agents. Use `../agent-manifest.json` for the full machine-readable contract and `catalog.json` for catalog records.

Playable runtime pages expose `#game-status[data-runtime-state]`, stable direct links, accessible controls, and the documented `data-agent-action` attributes. The optional hub mode is `https://playchive.ir/?agent=1`.
