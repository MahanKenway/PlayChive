PLAYCHIVE Agent Discovery

PLAYCHIVE is a browser-based hub for open-source, free-content classic games and experimental runtimes. This page is intentionally understandable without JavaScript, login, cookies or an API key.

Launch contract: direct runtime links are stable relative URLs. After opening a playable runtime, inspect #game-status with data-runtime-state for loading, ready, playing, paused, error or stopped. Runtime controls expose data-agent-action and accessible names.

How to operate a runtime

  1. Open a direct game link below.
  2. Wait for #game-status[data-runtime-state="ready"] or a visible READY message.
  3. Use labeled controls for pause, restart, fullscreen and return-to-hub; keyboard and touch controls remain available.
  4. Optional agent mode is available on the hub with ?agent=1.
